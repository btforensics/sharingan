How the per-item score works. Each item gets a Build Priority Score (0–100) = a blend of analysis impact, cost-efficiency (cheaper scores higher), and whether it unblocks other work. The +Δ chip is the estimated lift to the overall 93.5/100 tool score once built. Impact stars (★) rate analytical value independent of cost. Scores are an analyst's judgment call, not a measurement — they're meant to drive sequencing, not to be precise.
Gating & speed rubric — every new stage must declare how it runs. Sharingan is breadth-agnostic without getting slow because nothing runs that the file type doesn't need. The contract for any new analysis stage:
  1. Identify first. identify.py classifies (magic + file + structural peek, sub-second) and emits category/subtype + recommended_stages; triage.sh routes only those. A sample only ever pays for its own type.
  2. Cheap stages auto-run on type match. Decoders, parsers, structural reads, Mach-O capa, etc. run automatically when the category matches — they cost ~0 on every other type.
  3. Expensive stages are opt-in or bounded. Emulation, iterative script deobfuscation, disk-image mount/carve, APK→DEX decompile follow the --deep/--unpack pattern: behind a flag, or hard-capped. They must never bloat the common path.
  4. Recursion is capped. Any carve/extract stage (archive, ISO, OneNote, MSI, polyglot) bounds recursion depth, child count, and size, and skips expensive stages on children. Reuse the archive handler's limits.
Corollary (per the perf findings): routed CPU tools were never the bottleneck — VT rate-limit pacing (PERF-1) and the AI phase are. So adding well-gated breadth barely moves run time.

Automated unpacking stage ✓ SUPERSEDED by N4 + N7

Originally one card for "get the real payload out of a packed/protected sample, then re-run floss/capa on it." That capability now ships as two stages, so there's no standalone work left: N4 (Speakeasy) emulates a native loader stub and carves the payload; N7 (de4dot) strips a managed .NET protector and recovers the clean assembly. Separately, packed ELF isn't covered (Speakeasy is Windows-PE only) — tracked under the Linux-depth axis (a upx -d attempt + a Qiling/Unicorn ELF path), not here.

Emulation-based unpacking (Speakeasy) ✓ SHIPPED 2026-06-28

Done. New tools/unpack_emulate.py stage, opt-in via ./triage.sh <sample> --unpack (PE only). Emulates only the loader stub in Mandiant Speakeasy (Windows-API emulation — no VM, no detonation, no network), lets the stub self-decrypt in emulated memory, then carves the decrypted regions and re-runs floss/capa/YARA on the real body into an unpacked/ subdir. ⚠ Verified honestly — and it corrected an earlier overclaim. N6shipped

Authenticode / digital-signature verification ✓ SHIPPED 2026-06-29

Done. New tools/authenticode.py (signify, in the venv) wired into triage.sh for PE/.NET → authenticode.json. Beyond noting a signature exists (pestats), it verifies it: validates the cert chain + digest against the bundled MS trust store, checks the validity window, and raises flags — self_signed, hash_mismatch (tampered after signing), expired_at_analysis, weak_digest_md5/sha1 — plus an abused_cert/abused_cert_suspected correlation against the analyst-maintained rules/abused_certs.json (stolen/abused signing certs).

A bidirectional signal: valid from a recognizable vendor leans benign (rules benign in) — but EMBEDDED evidence only, so it never proves "clean" (stolen-cert abuse and trojanized-legit binaries are signed-and-valid too; hash_mismatch is the tell for the latter). invalid is itself a finding. Honest gaps: revocation (OCSP/CRL) is not checked offline; signify absent = unavailable (a GAP), never "not signed".

✓ Verified end-to-end 2026-06-29. On a dual-signed PuTTY pscp.exe → valid (signer Simon Tatham, SHA-1+SHA-256, weak_digest_sha1 flagged). A single flipped byte → invalid + hash_mismatch. av45i.exe → not_signed. Fixed a false-positive where bundled root CAs (self-signed by design) tripped self_signed — now leaf-only.

Impact ★★ Cost: Low signify + MS trust store +1 Δ applied (89.5→90.5)
