VirusTotal pivoting ✓ SHIPPED 2026-06-28

Done. New tools/vt_pivot.py stage wired into triage.sh → vt_pivot.json. Pivots on the VT report already fetched in step 2: forward footprint (contacted domains/IPs, dropped files, ITW URLs) and reverse pivots to sibling samples via communicating_files per indicator and an imphash intelligence search. N1candidate

VirusTotal behavior ingestion — a free "sandbox" when VT has one

Pull VT's existing detonation report via the /behaviours API: processes spawned, files & registry written, network contacted, mutexes, services created — but only when a dynamic sandbox actually ran the sample. We send only the hash; nothing is uploaded.

⚠ Verified 2026-06-28 on av45i.exe — and it came back near-empty. VT's only "behaviour" report for this sample is sandbox_name: CAPA (static), has_network:false, has_procs:false. No dynamic data exists — almost certainly because the worm targets pre-2007 Windows and won't run in VT's modern sandboxes. So here it would only re-fetch capa output Sharingan already produces. Real value is conditional: high for modern / widely-detonated malware, ~null for old / niche / targeted samples.

N4shipped

Emulation-based unpacking (Speakeasy) ✓ SHIPPED 2026-06-28

Done. New tools/unpack_emulate.py stage, opt-in via ./triage.sh <sample> --unpack (PE only). Emulates only the loader stub in Mandiant Speakeasy (Windows-API emulation — no VM, no detonation, no network), lets the stub self-decrypt in emulated memory, then carves the decrypted regions and re-runs floss/capa/YARA on the real body into an unpacked/ subdir. Bounded by an instruction cap + wall-clock (anti-hang); Speakeasy installed in the venv via setup-env.sh; version stamped into provenance.json. Emits unpacked.json (status/recovered/ primary_region/gap). Source tag [unpack].

⚠ Verified honestly — and it corrected an earlier overclaim. Proven end-to-end on a UPX-packed PE: the stub ran 852,607 emulated instructions and decompressed the payload back into memory (a marker string absent from the packed file reappeared; 605 new strings recovered). But av45i.exe's ~2005 crypter bails after 171 instructions under Speakeasy (unsupported API / anti-emulation) — so N4 did not crack av45i; it records that as a gap and points to the sandbox. The earlier "viable for av45i" note was optimistic — the stage now proves per-sample which case you're in instead of assuming. Recovers EMBEDDED indicators only (not confirmed live behaviour).

Impact ★★★★ Cost: Med (done) +3 Δ applied (81.5→84.5) Sandbox-free arm of #4 · honest gap when the stub stalls

N6candidate

Authenticode / digital-signature verification

Beyond noting a signature exists (peinfo does that), actually verify it: validate the cert chain, check validity/revocation, and surface the signer. Flag invalid/expired/self-signed and known stolen or abused certificates.

Signing status is a strong, cheap signal: signed-and-valid lowers suspicion, while a stolen/abused or broken signature is itself a finding. We already parse the signature blob — this adds the verdict the analyst actually needs.
